# GLA Studio

Desktop floor plan sketching tool for real estate appraisers, by [ApexPath](https://www.apexpath.com).

Draw rooms and walls, auto-calculate Gross Living Area, trace aerial imagery,
and use AI to detect rooms and fixtures from an uploaded floor plan image —
then export appraisal-ready PDF reports.
